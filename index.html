Rank Ladder & System Guide

Your complete field manual: rank requirements, XP curve, daily caps, assistant forms and operating rules.

Core rule

Rank is determined by level. XP unlocks levels; Skill Points unlock skill nodes. The daily XP cap rises only when you reach a new rank. Unused daily cap does not roll over.

Level & XP mathematics

For current level L, XP needed to advance one level is 100 + 20(L − 1). Total XP needed to reach level L, with n = L − 1, is 100n + 10n(n − 1). The XP bar shows progress within the current level.

XP to enter rank is calculated from the first level of that rank using the same formula. S, S+ and S++ are intended as long-term milestones, not monthly goals.

How to progress

1 · Complete objectives

Quests and habits award XP based on difficulty. Completion is recorded in the activity history.

2 · Respect the daily cap

Only the remaining XP allowance can be awarded for the current day. Ranking up increases the cap for future rewards.

3 · Build attributes

Assign each objective to one of six stats: Strength, Discipline, Intelligence, Vitality, Faith or Consistency. Difficulty contributes different stat growth.

4 · Spend Skill Points

Skill Points are separate from XP. Unlock nodes when level, rank, prerequisites and SP cost are all satisfied.

5 · Keep your data safe

Export a JSON backup before major changes or switching devices. Import only backups you trust.

6 · Use exceptions responsibly

Illness, emergencies and legitimate schedule changes should be recorded as exceptions rather than treated as ordinary failures.

Progression model

The level XP curve is calibrated to the agreed rank-entry thresholds: E 1,500 XP, D 4,500, C 10,000, B 20,000, A 35,000, S 60,000, S+ 100,000, and S++ 150,000. Rank bands: F 1–10, E 11–20, D 21–35, C 36–55, B 56–80, A 81–110, S 111–150, S+ 151–200, S++ 201+. Each level within a rank band has a consistent interpolated XP requirement; S++ levels continue at 1,000 XP per level.
