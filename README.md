SOLO SYSTEM
Turn your daily life into a system of quests, habits, progress, and rank progression.
SOLO SYSTEM is a Solo Leveling-inspired habit tracker and habit manager built around a rank-based progression system. Track your routines, build streaks, earn progress, and personalize your experience with your own mythical guardian artwork.
✨ Features
Habit tracking: keep your daily habits and routines organized.
Quest-style motivation: approach your goals as tasks to complete rather than chores to postpone.
Rank progression: work your way through the ranks from F to S++.
Progress and streaks: follow your consistency and build momentum over time.
Personalized experience: shape the system around your own goals and preferences.
Assistant Studio: assign a different PNG image to each of the nine ranks.
Custom guardians: use the built-in mythical-guardian concepts as a starting point, or replace them with artwork you prefer.
Installable web app: access SOLO SYSTEM through a supported browser; installation availability depends on your device and browser.
🏆 Rank System
SOLO SYSTEM uses nine ranks:
Rank   Theme
F      Light blue and white E      Dark blue D      Black and purple C      Golden yellow B      Crimson red A      Emerald green S      Angel white S+     Ash black S++    Heavy purple and black
The rank colours are part of the default theme. You can personalize the assistant artwork without needing to keep the default creature designs.
🐉 Personalize Your Assistant
Assistant Studio lets you choose a separate PNG for each rank.
Open SOLO SYSTEM.
Navigate to Others and open Assistant Studio.
Select the rank you want to customize.
Choose a PNG image from your device.
Preview the image, then apply it.
Repeat for any other ranks you want to personalize.
You can reset an individual rank to its default state or reset all rank images. Assistant Studio also supports exporting and importing a JSON backup of its image configuration.
Tips for choosing images
Use a clear PNG with the main subject centred.
Choose artwork that remains recognizable at small mobile sizes.
Keep each image visually distinct so you can easily identify the rank.
Match the artwork to the rank colour if you want to retain the default visual identity.
Your assistant artwork is a personal choice: use mythical creatures, original characters, symbols, or any image you prefer.
Where custom images are stored
Custom assistant images are saved in the browser's local IndexedDB storage on the device and browser where you upload them. They are not automatically uploaded to the GitHub repository or synchronized to another device.
If you clear the browser's site data, use a different browser, or move to another device, your custom images may not be available there. Export a backup from Assistant Studio if you want to keep a copy of your configuration. Keep your original PNG files as well.

🛠️ Troubleshooting
My custom assistant image is not appearing - Confirm that you selected the correct rank in Assistant Studio. - Try selecting the PNG again and applying it. - Reopen the app and check the selected rank. - Make sure you are using the same browser and device where you uploaded the image.
My custom images disappeared - Browser site data may have been cleared, or you may be using a different browser or device. - Restore a previously exported Assistant Studio JSON backup if you have one, and keep the original PNG files available.
The app is not installing - Installability depends on browser and device support and how the app is hosted. Try opening the published HTTPS website in your browser and use its available install option.
🔒 Privacy and Storage
Assistant Studio stores custom assistant images in your browser's local IndexedDB storage. These custom images are not automatically sent to the project's GitHub repository. Browser storage can be removed by clearing site data, so keep backups of images you want to preserve.
📦 Project Contents
The repository includes the web app and its supporting application assets and manifest. The assistant artwork can be customized by each user through Assistant Studio rather than requiring the default artwork to be permanently bundled with the app.
